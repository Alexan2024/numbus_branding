# NUMBUS Branding

Telegram-бот, который оформляет фото в фирменном стиле клиента. Стиль клиент
собирает сам в редакторе (Telegram Mini App): где стоит логотип, какой шрифт у
заголовка, нужна ли плашка, градиент или рамка, есть ли сторис. Посты делаются
в чате: шаблон → фото → текст → формат → готовые файлы. Один бот обслуживает
много брендов; доступ — по инвайт-кодам.

## Файлы

| Файл | Что внутри |
|---|---|
| `bot.py` | Диалоги: код → название → логотип → редактор; создание постов; команда; админ-команды. Запускает и бота, и сервер редактора |
| `web.py` | Сервер редактора: отдаёт `webapp.html`, API бренда и шаблонов, проверка подписи Telegram |
| `webapp.html` | Сам редактор (Mini App): бренд-кит и конструктор шаблонов с живым превью |
| `render.py` | Движок рендера: шаблон = список слоёв. Превью в редакторе повторяет его пиксель в пиксель |
| `spec.py` | Схема шаблона (проверка всего, что приходит из редактора) и стартовые стили |
| `db.py` | SQLite: бренды, участники, ассеты, шаблоны, коды, статистика; тарифы — `PLANS` |
| `texts.py` | Тексты бота на русском и английском |
| `Dockerfile`, `requirements.txt` | Сборка для Railway (16 шрифтов скачиваются при сборке) |

## Запуск на Railway

1. **Бот.** @BotFather → `/newbot` → токен. Там же `/setcommands`:
   ```
   start - Меню
   cancel - Отменить
   ```
2. **Репозиторий.** Приватный репозиторий `numbus-branding` → Add file → Upload files →
   перетащить все файлы разом.
3. **Railway.** New Project → Deploy from GitHub repo → `numbus-branding`.
4. **Публичный адрес — нужен редактору.** Settings → Networking → **Generate Domain**.
   Railway сам передаст адрес в переменную `RAILWAY_PUBLIC_DOMAIN`, бот подхватит.
   Если используешь свой домен — задай `WEBAPP_URL=https://твой.домен`.
5. **Переменные** (Variables):
   - `BOT_TOKEN` — токен от BotFather
   - `ADMIN_IDS` — твой Telegram ID (несколько — через запятую)
   - `SUPPORT_CONTACT` — куда писать клиентам, например `@aleskan`
   - `RENDER_WORKERS` — необязательно, по умолчанию 2
   - `PORT` — Railway ставит сам, трогать не нужно
6. **Volume — обязательно.** Settings → Volumes → Add Volume, mount path любой
   (например `/data`). Без него база обнуляется при каждом деплое.

Проверка: `/brands` покажет «Хранилище: постоянное» и адрес редактора.
Если вместо адреса «не задан WEBAPP_URL» — не сделан шаг 4.

## Как устроен стиль клиента

**Бренд-кит:** название, два логотипа (основной и дополнительный), палитра из
пяти цветов, до трёх своих шрифтов (TTF/OTF), хештеги, фото для превью.

**Шаблон** — это стопка слоёв, отдельно для ленты и (по желанию) для сторис:

| Слой | Настройки |
|---|---|
| Логотип | какой из двух, ширина, цвет, непрозрачность |
| Текст | заголовок / подзаголовок / хештег / счётчик «1 / 8» / своя надпись; шрифт, насыщенность, кегль, трекинг, интерлиньяж, регистр, выключка, ширина строки, плашка |
| Фигура | прямоугольник или круг, заливка или контур; или рамка по краю кадра |
| Градиент | сторона, высота, цвет, «плотнее на светлом фоне» |
| Затемнение | цвет и плотность на весь кадр |

Каждый слой привязывается к одной из 9 точек кадра, поэтому шаблон одинаково
ложится на 4:5, 1:1, 3:2 и другие форматы. Цвет — фиксированный, из палитры
(меняешь палитру — меняются все шаблоны), «Авто» (тон фона светлее/темнее) или
«Контраст» (светлый на тёмном, тёмный на светлом).

**Стартовые стили** (`spec.py → PRESETS`): Знак, Метка, Редакция, Блок, Рамка,
Карусель, Центр, С нуля. Намеренно разные по характеру и не повторяют ÖMANKÖ —
это отправная точка. Новому бренду сразу создаются «Знак» и «Редакция».

**Бот спрашивает только нужное:** заголовок — если он есть в шаблоне,
подзаголовок — если есть (можно пропустить), хештег — если есть, ползунок
затемнения — если в шаблоне есть градиент или затемнение.

## Безопасность редактора

- Редактор открывается только кнопкой в боте. Каждый запрос подписан Telegram
  (`initData`), подпись проверяется токеном бота; подписи старше суток не принимаются.
- Редактировать может только владелец бренда. Участники команды делают посты,
  но редактор не видят.
- Всё, что приходит из редактора, проходит через `spec.sanitize_spec`: неизвестные
  поля выбрасываются, числа зажимаются в допустимые диапазоны, не больше 30 слоёв.

## Админ-команды (видны только ADMIN_IDS)

| Команда | Что делает |
|---|---|
| `/newcode [тариф] [дней] [использований]` | Создать инвайт-код. По умолчанию `pilot 30 1`. Ответ содержит готовый текст для клиента |
| `/codes` | Последние 30 кодов и сколько раз использованы |
| `/brands` | Все бренды: тариф, срок, участники, шаблоны, фото за месяц; статус хранилища и редактора |
| `/extend <id> <дней> [тариф]` | Продлить бренд и при желании сменить тариф |
| `/myid` | Узнать свой Telegram ID |

Тарифы и лимиты — словарь `PLANS` в `db.py`. Лимит шаблонов на бренд — `MAX_TEMPLATES` (30).

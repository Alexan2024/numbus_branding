# NUMBUS — шаблон v4 (ветка layout-v4, от main 08186d5)

## Что нового
**Шаблон (движок, схема, редактор):**
- Слой **«Фото в рамке»**: фото поста в прямоугольнике или с полями от края; скругление,
  своя точка фокуса, масштаб до ×4. Фон кадра вокруг — цвет слоя.
- **Выделение `*…*`** в заголовке, подзаголовке и надписи: у слоя свой стиль выделения —
  цвет, вес, шрифт (в том числе свой шрифт из слота). Без звёздочек текст рисуется как раньше.
- **«Под слоем»**: текст встаёт под другим слоем с отступом. Подзаголовок не наезжает
  на заголовок любой длины.
- **Рубрика «Без # и _»**: `#Vive_la_différence` → «Vive la différence».
- **Градиент от отступа** («Начало от края»): до начала — сплошной цвет.
- Форматы **16:9** и **1.91:1** (превью ссылки, X, Facebook).

**Бот:**
- Жирный текст в подписи Telegram → выделение (смещения UTF-16, эмодзи учтены).
  В тексте поста для канала звёздочек нет.
- В пульте — масштаб фото «− ×1.25 +» (до ×3), для каждого кадра карусели свой.
- Подсказка об обрезке и кнопки фокуса учитывают рамку фото.

## Проверка
- Тесты: 83 проходят (71 прежних + 12 новых, `tests/test_layout_v4.py`).
- Превью редактора против рендера сервера (Chromium, шаблон со всеми новыми слоями):
  среднее расхождение 1,46 из 255.
- Старые шаблоны: поля новые и необязательные. Без них вёрстка не меняется (проверено тестом).

## Как поставить
Вариант 1 — bundle:
```
git fetch numbus_branding-layout-v4.bundle layout-v4:layout-v4
git push origin layout-v4
```
Вариант 2 — патч: `git am layout-v4.patch` (на main 08186d5).
Вариант 3 — заменить файлы из `changed-files.zip`.
После мержа на сервере: `git pull && docker compose up -d --build`.

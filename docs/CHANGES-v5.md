# NUMBUS — шаблон по образцу (v5, поверх v4)

## Что нового
- Кнопка «Шаблон по образцу» в меню (владелец и дизайнер, после настройки стиля).
- Клиент присылает свой фирменный пост → через 20–40 секунд «образец / шаблон» рядом →
  «Сохранить стиль», «Собрать ещё раз», «Другой образец». Сохранённый стиль становится
  выбранным, формат — как у образца (4:5, 1:1, 1.91:1 и т. д.).
- `sample.py`: модель с картинками описывает макет, подгонка шрифта, кегля, интерлиньяжа и
  места — локально по маске букв движком NUMBUS; рамка фото и плашки уточняются по пикселям.
- Слабые совпадения бот называет в подписи; шрифты из каталога — тоже, с советом загрузить свой.

## Настройка
В `.env`: `VISION_PROVIDER` (`openai` или `anthropic`), `VISION_API_KEY`, `VISION_MODEL`,
при необходимости `VISION_BASE_URL`, `VISION_TIMEOUT`. Без ключа кнопка отвечает «не подключено».
Добавлен `.env.example` — README на него ссылался, но файла в репозитории не было.

## Проверка
- Тесты: 92 проходят (83 после v4 + 9 новых, `tests/test_sample.py`): подгонка на образцах,
  нарисованных самим движком (известный ответ), рамка, плашка, выделение, оба формата API,
  сквозной сценарий в боте.
- Шесть реальных эталонов (РБК, FT, Economist, TRT, Hypebeast, Bloomberg) с описанием макета
  вместо ответа модели: совпадение вёрстки 0,57–0,95.
- Реальный вызов модели не проверен: в тестовой среде нет ключа.

## Как поставить
Поверх v4 (или сразу на main — в архиве все изменённые с main файлы).
После мержа: заполнить `VISION_*` в `.env`, затем `git pull && docker compose up -d --build`.
